# スカイライン・テクノロジーズ 企業サイト

スカイライン・テクノロジーズのコーポレートサイトです。クラウド基盤からアプリケーションまでを一貫して設計・開発するソフトウェア開発会社として、事業内容や実績を紹介します。

## 概要

`index.html` 1ファイルで動く静的サイトです。ビルドもサーバーも要りません。

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピー「基礎から積み上げる、高く、倒れないソフトウェア。」 |
| サービス (`#services`) | 4つの事業領域（UI/UXデザイン・アプリ開発／データ基盤・AI活用／バックエンド・API開発／クラウド基盤・運用保守） |
| 実績 (`#works`) | 配送ルート最適化、クリニック向け予約・問診、需要予測にもとづく自動発注の事例 |
| 進め方 (`#process`) | 調査 → 設計 → 開発 → 検査 → 運用 の5段階 |
| 会社概要 (`#company`) | 会社情報 |
| お問い合わせ (`#contact`) | 問い合わせフォーム |

### 技術構成

- HTML / CSS / JavaScript（すべて `index.html` に記述）
- フォントは Google Fonts から読み込み（Archivo、IBM Plex Mono、Zen Kaku Gothic New）
- お問い合わせフォームの入力チェックはブラウザ内で行います。送信先のサーバーとはつながっていません。

## ブラウザで開く手順

### 方法1: ファイルを直接開く

1. Finder でこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。既定のブラウザでページが開きます。
   - ブラウザを選ぶ場合は、`index.html` を右クリックし「このアプリケーションで開く」から Chrome や Safari などを選びます。
   - ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

ターミナルからは次のコマンドで開けます（macOS）。

```sh
open index.html
```

### 方法2: ローカルサーバーで開く

`http://` のURLで確認したい場合は、このフォルダで簡易サーバーを起動します。

```sh
python3 -m http.server 8000
```

起動したら、ブラウザで <http://localhost:8000> を開きます。終了するときは、ターミナルで `Ctrl + C` を押します。

> フォントは Google Fonts から読み込むため、正しい書体で表示するにはインターネット接続が必要です。
